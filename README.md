# 💰 Advanced Personal Expense Tracker in C

A console-based **Personal Expense Tracker written in C** that allows users to record, manage, analyze, and monitor their expenses.

The project includes expense management, CSV-based data storage, monthly budgeting, salary tracking, budget warnings, reports, statistics, searching, sorting, and CSV export.

## ✨ Features

The program provides **15 main modules**:

1. **Add Expense** – Add an expense with date, category, description, and amount.
2. **View All Expenses** – Display all recorded expenses.
3. **Total Expenses** – Calculate total recorded spending.
4. **Search by Category** – Find expenses belonging to a particular category.
5. **Set Salary & Monthly Budget** – Store monthly income and spending budget.
6. **Monthly Budget Status** – Check spending against the configured budget.
7. **Delete Expense** – Delete an expense using its ID.
8. **Edit Expense** – Modify an existing expense.
9. **Search by Date** – Find expenses recorded on a particular date.
10. **Monthly Report** – Display expenses for a selected month and year.
11. **Category Analysis** – Calculate total spending for each category.
12. **Highest Expense** – Find the largest recorded expense.
13. **Sort by Amount** – Display expenses sorted by amount.
14. **Statistics** – Display total, average, minimum, maximum, and number of expenses.
15. **Export to CSV** – Export expense records to a separate CSV file.

## 💵 Salary & Budget System

The user can configure a **monthly salary/income** and a **monthly spending budget**.

Whenever a new expense is entered, the tracker checks the total spending for that month. If the expense would exceed the monthly budget, the program displays a warning and asks whether the user wants to add the expense anyway.

The salary acts as an additional spending limit to help prevent spending beyond the configured monthly income.

## ⚠️ Startup Budget Warning

When the program starts, it loads saved expenses and financial settings and checks the current month's spending. If the configured spending limit has already been reached or exceeded, the program displays a warning.

## 💾 Data Storage

The program uses separate CSV files:

- `tracker_expenses.csv` – stores expense records used by the program.
- `financial_settings.csv` – stores salary and monthly budget settings.
- `expenses_export.csv` – generated by the Export to CSV module.

Each expense contains an ID, date, category, description, and amount.

## 🚀 Compile and Run

Make sure **GCC** is installed.

### Compile

```bash
gcc expense_tracker_csv_budget_warning.c -o expense_tracker
```

### Windows

```powershell
.\expense_tracker.exe
```

### Linux / macOS

```bash
./expense_tracker
```
